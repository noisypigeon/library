| <a name="input_enable_transcoding"></a> [enable\_transcoding](#input\_enable\_transcoding) | Install a pinned, checksum-verified static ffmpeg 9.0.2 build into /usr/local/bin, for job commands that run `pigeon-cli transform` (ADR-0150, renamed by ADR-0151, reworked by ADR-0152). The pinned artifact is an x86\_64 (linux64) binary: do not enable this for an arm64 instance type such as COPARM1-*. | `bool` | `false` | no |

Requires self\_delete\_credentials. | `bool` | `false` | no |
